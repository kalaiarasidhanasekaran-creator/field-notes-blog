# The Art of Being Kalai

A nature-inspired personal journal and portfolio site hosted with GitHub Pages.

## Add a journal story

1. Open [the journal form](https://github.com/kalaiarasidhanasekaran-creator/field-notes-blog/issues/new?template=journal-post.yml).
2. Choose a topic, add a short introduction, and write your story.
3. Submit the form. Your public post appears on the site automatically.

## Add portfolio work

Use [the portfolio form](https://github.com/kalaiarasidhanasekaran-creator/field-notes-blog/issues/new?template=portfolio-work.yml) to describe your work and add an optional project link or image.

GitHub Issue Forms are used as the no-code publishing interface. The public site reads published entries from the repository's Issues API, so no access token or website code edits are needed for ordinary posts.
