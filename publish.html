YOUR LITTLE CORNER, YOUR WORDS

How to add your work.

New post or project? Add it to the source files in GitHub, save the change, and the live site updates automatically.

01

Open your journal file

Open app.js in the repository. Choose Edit (the pencil icon), then find the posts list and add a new entry object.

02

Write it in your voice

Give it a title, topic, date, short intro, and paragraphs. Keep each paragraph in the body list. Save your changes with Commit changes.

03

Add a portfolio piece

Upload your image into an images folder in the repository. Edit portfolio.js to add a project tile and point it to your image.

A journal entry looks like this

{
  id: 7,
  category: 'Technology', // Technology, Life, or Ideas
  date: '2026-10-18',
  title: 'Your title goes here',
  excerpt: 'A one-sentence preview of your story.',
  icon: '✳',
  read: '3 MIN READ',
  subtitle: 'A little line to set the scene.',
  body: ['Your first paragraph.', 'Your next paragraph.']
}

Place a comma after the previous entry, then add yours before the closing ];. To replace a starter post, edit its words in place.

Portfolio image entry

{ title: 'Project name', category: 'Creative', type: 'visual-flower', image: 'project.jpg', caption: 'ILLUSTRATION', description: 'A short note about the work.' }

Upload project.jpg into the repository first. The site reads that image path from portfolio.js.

OPEN JOURNAL FILE ↗OPEN PORTFOLIO FILE ↗UPLOAD IMAGES ↗OPEN THE REPOSITORY ↗

After you commit, GitHub Pages rebuilds the site for you. It can take a minute or two for the new version to appear.
